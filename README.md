## Présentation

Les récoltes de cultures ont une chance de donner des loots bonus (items custom, clés, exp).

Utilisé sur : **Opale**.

## Commandes

| Commande | Alias | Description | Permission |
|---|---|---|---|
| `/shcropsloots` | — | Gestion des loots de cultures | `shcropsloots.admin` |

## Permissions

| Permission | Description | Par défaut |
|---|---|---|
| `shcropsloots.admin` | Permet de gérer les loots des cultures | `op` |

## Configuration

Fichiers par défaut repris du serveur (secrets remplacés par `CHANGE_ME`). Cliquez sur un fichier pour l'ouvrir :

<pre>
plugins/SHCropsLoots/
└── <a href="src/main/resources/config.yml">config.yml</a>
</pre>

## Compilation

Java 25 et Maven :

```bash
mvn clean package
```

Le jar est généré dans `target/`.
